# أدوات PDF

تطبيق ويب عربي (لهجة أردنية) لأدوات تعديل وإنشاء ملفات PDF. كل المعالجة تتم بالكامل داخل متصفح المستخدم — ولا يُرفع أي ملف إلى أي خادم.

## الأدوات
- 🧩 **دمج ملفات** — جمع عدة ملفات PDF بملف واحد مع إمكانية إعادة الترتيب بالسحب.
- ✂️ **تقسيم / استخراج** — استخراج صفحات محددة (مثل `1-3,5,8`).
- 🖼️ **صور إلى PDF** — تحويل صور JPG/PNG إلى ملف PDF (حجم أصلي أو A4).
- ➕ **إضافة صورة** — لصق صورة على صفحة بموضع وحجم محددين.
- ✍️ **إضافة نص** — كتابة نص أو توقيع مع دعم الحروف العربية.
- 🔄 **تدوير صفحات** — تدوير الصفحات 90/180/270 درجة.
- 🗑️ **حذف صفحات** — حذف صفحات غير مرغوبة.
- 🔀 **ترتيب صفحات** — إعادة ترتيب الصفحات.
- 📝 **إنشاء PDF** — إنشاء مستند جديد من عنوان ونص عربي.

## المزايا
- 🌙 وضع ليلي/نهاري مريح للعين مع حفظ التفضيل.
- خط **Cairo** الواضح ودعم كامل للاتجاه من اليمين لليسار (RTL).
- يعمل بدون خادم (static) — مناسب للاستضافة على أي CDN.

## التشغيل محليًا
```bash
cd pdf-tools
python3 -m http.server 4173 --bind 127.0.0.1
# ثم افتح http://127.0.0.1:4173/
```

## التقنيات
- [pdf-lib](https://pdf-lib.js.org/) لتعديل وإنشاء ملفات PDF.
- [@pdf-lib/fontkit](https://github.com/Hopding/fontkit) لتضمين خط عربي.
- خط Cairo من Google Fonts / fontsource.

> ملاحظة: تُحمَّل المكتبات والخط العربي من CDN، لذا يلزم اتصال إنترنت عند أول استخدام.
