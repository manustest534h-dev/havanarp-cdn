# دفترنا

تطبيق ملاحظات أندرويد عربي بلهجة أردنية خفيفة وواضحة. يعمل بالكامل بدون إنترنت ويحفظ البيانات محلياً على الجهاز.

## المزايا

- إضافة وتعديل وحذف الملاحظات.
- بحث فوري داخل العنوان والتفاصيل.
- تثبيت الملاحظات المهمة في الأعلى.
- تصنيفات للشغل، البيت، الدراسة، والملاحظات الشخصية.
- أرشفة واسترجاع الملاحظات.
- ألوان مختلفة ومشاركة ملاحظة واحدة أو كل الملاحظات.
- واجهة RTL ودعم أندرويد 6.0 فما فوق.

## البناء

يتطلب JDK 17 وAndroid SDK 35 وGradle 8.9:

```bash
export ANDROID_HOME=/opt/android-sdk
./gradlew --no-daemon test lintDebug assembleRelease
```

ملف APK الناتج موجود في `app/build/outputs/apk/release/app-release.apk`.

> الملاحظات لا تُرفع لأي خادم، والنسخ الاحتياطي السحابي للتطبيق معطّل لحماية خصوصية المستخدم.
